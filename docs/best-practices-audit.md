# Best-practices audit

Postern against the Builder's PWA best practices: every line of the quick-reference checklist and
every rule added on 2026-10-09 (the vault's `seats/builder/pwa-best-practices/checklist.md` and
`changelog.md`). Written 2026-10-09 at version 0.5.21 for mw-vtjxh4.29 (docs only; it changes no
behaviour). The Governor asked on 2026-10-09 (Postern general, 18:37Z) that all his apps be brought up to the
practices we have spoken about; this is Postern's part.

**How to read it.** Postern is a PWA (the root of the repo) with a Go backend under `server/`; the
backend is not a PWA, so the PWA rows below are about the app only, and the Go side is n/a for all of
them. Status is `pass`, `fail` or `n/a`. A path written as `file:line` names a file that exists at this
commit; the audit's own check fails when one does not. A command is given with the output it printed
here. "UNVERIFIED" means the repository cannot show it: only his phone can. Sizes: S is one story of
under an hour (a few lines and one test), M is one story of a few hours, L would need splitting.

Method: I read the checklist and each section it points to, then looked in the code, ran `npm run build`
and read the built `dist/sw.js` and `dist/manifest.webmanifest`, and ran `curl -sI https://postern.allmymind.org/`.
I did not run Postern on a phone.
